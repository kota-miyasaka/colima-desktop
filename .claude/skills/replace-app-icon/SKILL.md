# replace-app-icon — アプリ/トレイアイコンの生成・差し替え

colima-desktop で、渡されたPNG画像を次の2種類のアイコンに自動加工して差し替える。

| 用途 | 出力 | 加工 |
|------|------|------|
| アプリアイコン (Dock / Finder / .app) | `src-tauri/icons/` 一式 (`icon.icns`, `128x128.png` ほか) | macOS標準の**角丸スクワークル**に配置(周囲マージン付き) |
| トレイアイコン (macメニューバー) | `src-tauri/icons/tray-icon.png` (44x44 透過PNG) | 白背景を透過した**白黒シルエット**として表示される |

## 入力画像の確認（実行前に必ず行う）

入力画像は **1枚のことも2枚のこともある**。実行前に、どの画像をどちらのアイコンに使うかを確定させる。

- **画像が1枚のとき**: 同じ画像をアプリ用とトレイ用の両方に使う。そのまま進めてよい。
- **画像が2枚のとき**: 片方をアプリ用、もう片方をトレイ用に割り当てる。**どちらをアプリ用・どちらをトレイ用にするかは自明ではない**ので、ユーザーに確認してから実行する。例:「2枚のうち、アプリアイコン(Dock)に使うのはどちら、メニューバーのシルエットに使うのはどちらにしますか？」。用途特性(アプリ用は絵柄がしっかり見える方、トレイ用は輪郭がはっきりした単純な方が向く)を添えて尋ねると選びやすい。
- 画像パスが不明なら、まずどの画像を使うかを確認する。`~/Downloads` にある想定なら実際のファイル名（スペースや日本語を含むことがある）をそのまま二重引用符で渡す。

## 使い方

割り当てが決まったら同梱スクリプトを実行する。**第1引数=アプリ用、第2引数=トレイ用**。第2引数を省略すると1枚を両方に使う。

```bash
# 1枚を両方に使う場合
bash .claude/skills/replace-app-icon/scripts/generate-icons.sh <画像.png>

# アプリ用とトレイ用に別画像を使う場合（順序に注意: アプリ用 → トレイ用）
bash .claude/skills/replace-app-icon/scripts/generate-icons.sh <アプリ用.png> <トレイ用.png>
```

**片方だけ差し替えたいとき**は、差し替えない側に `none` を渡す。ユーザーが「アプリアイコンだけ変えて（トレイはそのまま）」のように片方のみを求めた場合はこちらを使う。

```bash
# アプリアイコンだけ差し替え（トレイは現状維持）
bash .claude/skills/replace-app-icon/scripts/generate-icons.sh <アプリ用.png> none

# トレイアイコンだけ差し替え（アプリは現状維持）
bash .claude/skills/replace-app-icon/scripts/generate-icons.sh none <トレイ用.png>
```

実行後、アイコンを実際に反映するには**再ビルドが必要**である旨を伝える:

```bash
npm run tauri build   # .app にアイコンを焼き込む（開発確認なら npm run tauri dev）
```

## 仕組み（調整したいときのために）

スクリプト [scripts/generate-icons.sh](scripts/generate-icons.sh) は次を行う。数値を変えれば見た目を調整できる。

### アプリアイコン
元画像を data URI で埋め込んだSVGを組み、`npx tauri icon` に渡して各サイズ + `icon.icns` を生成する。SVGの構図は macOS のアイコングリッドに合わせている:

- キャンバス `1024x1024`、アイコン本体は中央 `824x824` の角丸矩形（四辺 `100px` マージン）
- 角丸半径 `rx=185`（本体幅の約22%＝macOS標準に近い）
- 絵は本体内の `724x724` 領域に `preserveAspectRatio="xMidYMid meet"` で収める（本体からさらに `50px` のセーフエリア）
- 背景は白 `#ffffff`

**余白を詰めて絵を大きく見せたい**なら `x/y/width/height` の `150,150,724,724` を `120,120,784,784` などに広げる。**角を丸くしすぎ/足りない**なら `rx/ry` を増減する。

### トレイアイコン
`sips` で元画像を `44x44`（メニューバーの22ptをRetina/2xで表示する解像度）の BMP に縮小し、Python(標準ライブラリのみ、`zlib`でPNGを直接組み立て)で白背景（RGBが全て `235` 以上）を透過、それ以外は元の色を保持したまま不透明にした実PNGを `src-tauri/icons/tray-icon.png` に書き出す。

トレイは `src-tauri/src/lib.rs` の `setup_tray()` で `include_bytes!("../icons/tray-icon.png")` として読み込み、`tauri::image::Image::from_bytes()` でPNGをデコードして **ビルド時に埋め込まれる**（`Cargo.toml` の `tauri` フィーチャに `image-png` が必要）。`icon_as_template(true)` により表示時は **色が無視されアルファ形状だけの白黒シルエット**になる（macOSのメニューバー仕様）。ファイル自体は色情報を保持した通常のPNGなので、`Read`ツールなどでそのまま見た目を確認できる。

**線が細くて潰れる**なら、しきい値 `TH=235` を下げると拾う面積が増える（例 `TH=200`）。逆に**背景ノイズを消したい**なら上げる。

## 前提・注意

- 依存: `sips`（macOS標準）, `python3`, プロジェクトの `@tauri-apps/cli`。プロジェクトルートで実行すること（スクリプトは自動で `cd` する）。
- 元画像は**正方形・白背景**が最も綺麗に収まる。透過PNGでも動くが、角丸本体の白背景の上に描画される。
- このスキルは **colima-desktop 専用**。`src-tauri/icons/`（`icon.icns`一式と`tray-icon.png`）と `lib.rs` のトレイ構成を前提にしている。`Cargo.toml` の `tauri` フィーチャに `image-png` が入っている前提（入っていなければ `tauri::image::Image::from_bytes()` はコンパイルエラーになる）。
- 生成物はバイナリのため、必ず上記スクリプト（`sips`/`tauri icon`/`python3`）で作ること。テキストエディタや手書きでは作れない。
